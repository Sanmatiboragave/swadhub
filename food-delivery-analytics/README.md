# Food Delivery Analytics — Phase 1

This repository is a realistic food-delivery analytics project scaffold for a data analyst portfolio.

Phase 1: project structure and environment setup (this folder).

What I created:
- Project skeleton with folders for `app`, `backend`, `database`, `data` (raw/cleaned/processed), `notebooks`, `sql`, `dashboards`, `reports`, `scripts`, `tests`.
- A `requirements.txt` for core Python packages used in later phases.
- Setup scripts placeholders.

Next steps (Phase 2 will be started after you confirm):
1. Design the PostgreSQL schema in `database/schema.sql`.
2. Generate realistic raw data into `data/raw/` using scripts in `scripts/`.

How to use this scaffold locally:

1. Create a Python virtual environment and activate it.

On Windows (PowerShell):

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

On macOS/Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

2. Jupyter Notebooks will be placed in `notebooks/` for the analysis pipeline.

3. Database schema will be in `database/schema.sql` (Phase 2).
